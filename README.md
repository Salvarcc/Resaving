# Resaving 🌿

> Aplicación web para la identificación clara de residuos, preparación adecuada y entrega en puntos de acopio confiables.

Proyecto desarrollado para el curso **HCI for UX Design (IV Ciclo)** - UPC.

## 📌 Alcance del Proyecto
Implementación del prototipo web interactivo basado en los mockups oficiales diseñados en Figma:
- **HU-001**: Buscar un residuo por su nombre (Pantalla Principal / Hero y Header).
- **HU-003**: Explorar residuos por 4 categorías oficiales.
- **HU-005**: Búsqueda asistida por fotografía.
- **HU-009**: Ficha de detalle de residuo y criterios de aceptabilidad.
- **HU-017**: Guía de preparación y acondicionamiento.
- **HU-025**: Directorio y mapa de puntos de acopio verificados.
- **HU-034**: Registro de entrega programada ("Mi entrega").

## 🛠️ Tecnologías Utilizadas
- **HTML5 Semántico** (`<header>`, `<nav>`, `<main>`, `<section>`, `<form>`, `<footer>`)
- **CSS3 Puro** (Modelo de Caja, Flexbox, variables de color y diseño accesible)
- **Vanilla JavaScript** (Interacciones del DOM)
- **Diseño Responsive** (Desktop & Mobile)

## 🚀 Visualización
Para visualizar el proyecto localmente, abrir `index.html` en cualquier navegador web moderno.
